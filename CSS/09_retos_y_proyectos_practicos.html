💡 Consejos para construirlo
  • Usa background: linear-gradient(...) para el fondo de la cabecera.
  • Usa border-radius: 50% para hacer el avatar redondo.
  • Usa un margen negativo como margin-top: -35px para superponer el avatar sobre la cabecera.
  • Agrega transition: transform 0.3s ease y :hover { transform: translateY(-8px); }.
