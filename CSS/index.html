🎨 Curso Práctico de CSS3: De Cero a Diseñador Web

Aprende a estilizar, diagramar y dar vida a tus páginas web paso a paso con código detalladamente comentado.

  • 🏛️ Lección 00: Arquitectura Interna de CSS, La Cascada y Especificidad

    El algoritmo de cálculo de especificidad (0,0,0,0), herencia, colapso de márgenes y contextos de apilamiento con z-index.

  • Lección 01: Sintaxis, Formas de Inclusión y Selectores Básicos

    Anatomía de una regla CSS, selectores de etiqueta, clase (.), ID (#), agrupados y descendientes.

  • Lección 02: Colores, Tipografía y Fondos

    Modelos de color (HEX, RGB, HSL), fuentes (font-family, size, weight), alineación y decoración de texto.

  • Lección 03: El Modelo de Cajas (Box Model)

    El concepto más importante de CSS: Content, Padding, Border, Margin y box-sizing: border-box.

  • Lección 04: Display y Posicionamiento

    Block, inline, inline-block, none, y posiciones: static, relative, absolute, fixed, sticky y z-index.

  • Lección 05: Flexbox (Diseño Flexible Unidimensional)

    Ejes, justify-content, align-items, flex-direction, flex-wrap, gap, flex-grow y alineación perfecta.

  • Lección 06: CSS Grid (Diseño Bidimensional)

    Filas y columnas simultáneas, fracciones (fr), repeat(), minmax(), grid-template-areas y auto-fit.

  • Lección 07: Responsive Design y Media Queries

    Adaptar sitios web a celulares y tablets con @media, unidades relativas (rem, %, vw, vh) y Mobile First.

  • Lección 08: Transiciones, Transformaciones y Animaciones

    Efectos de hover suaves, escalado, rotación, traslación y animaciones automáticas con @keyframes.

  • 🛠️ Lección 09: Taller de Retos y Proyectos Visuales (¡A Diseñar!)

    Construye componentes reales: Tarjeta de perfil con degradados y elevación, Tabla de precios y Landing page responsiva.

💡 Claves para dominar CSS

  • Abre el inspector con F12: Podrás ver cómo cada línea de CSS afecta en vivo a cada caja de la pantalla.
  • Juega cambiando valores: Cambia colores, aumenta márgenes, elimina propiedades para ver exactamente qué pasaba sin ellas.
  • Recuerda la metáfora: HTML es el esqueleto de la casa 🦴, CSS es la pintura y decoración 🎨, y JavaScript es la electricidad y mecanismos ⚡.
