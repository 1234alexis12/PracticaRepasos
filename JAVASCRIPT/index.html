⚡ Curso Práctico de JavaScript (ES6+)

Aprende la lógica de programación, algoritmos y control interactivo del navegador con explicaciones minuciosas.

  • 🏛️ Lección 00: Arquitectura del Motor V8, Event Loop y Memoria

    Call Stack, Memory Heap, paso por valor vs referencia, Closures privados y orden de Microtasks vs Macrotasks.

  • Lección 01: Variables, Constantes y Tipos de Datos

    Diferencias entre let, const y var. Tipos primitivos: String, Number, Boolean, Null, Undefined y Template Strings.

  • Lección 02: Operadores y Estructuras Condicionales

    Comparación estricta (=== vs ==), operadores lógicos (&&, ||, !), if / else if / else, switch y operador ternario.

  • Lección 03: Bucles e Iteraciones

    Repetición automatizada con for, while, do-while, for...of (colecciones) y control de flujo con break/continue.

  • Lección 04: Funciones, Parámetros y Scope

    Funciones declaradas, funciones de flecha (Arrow Functions: () => {}), return, parámetros por defecto y ámbito léxico.

  • Lección 05: Arreglos (Arrays) y Métodos Modernos

    Listas de datos, mutación (push, pop, splice) y métodos funcionales inmutables (map, filter, reduce, find, forEach).

  • Lección 06: Objetos Literales, Desestructuración y JSON

    Estructuras clave-valor, métodos de objeto, desestructuración ({ prop }), spread operator (...) y parseo de JSON.

  • Lección 07: Manipulación del DOM (Document Object Model)

    Seleccionar elementos (querySelector), modificar texto (textContent), clases CSS (classList) y crear nodos en vivo.

  • Lección 08: Eventos y Experiencia de Usuario

    Escuchar clicks, entradas de teclado, formularios con preventDefault() y manipulación interactiva de interfaces.

  • Lección 09: Asincronía, Promesas, Async/Await y Fetch API

    Manejo de operaciones lentas, promesas, la sintaxis moderna async/await y consumo de APIs de internet con fetch().

  • 🛠️ Lección 10: Taller de Proyectos Prácticos (¡A Programar!)

    3 aplicaciones interactivas en vivo: To-Do List completa, Generador de Frases y Buscador en Tiempo Real.

🛠️ Cómo sacar el máximo provecho

  • Consola del Navegador: Presiona F12 o Ctrl + Shift + I en cualquier lección y mira la pestaña Console.
  • Archivos .js puros: En esta misma carpeta encontrarás los archivos .js equivalentes que puedes correr con Node.js en consola.
