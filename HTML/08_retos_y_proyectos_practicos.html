NIVEL: FÁCIL

Reto 1: Tu Ficha de Perfil Profesional

Objetivo: Crear una página personal que contenga:

  • Un encabezado principal <h1> con tu nombre.
  • Una imagen de perfil <img> con texto alternativo alt.
  • Un párrafo <p> con una breve biografía usando <strong> y <em>.
  • Una lista desordenada <ul> con tus 3 tecnologías favoritas.
  • Un enlace <a> hacia tu cuenta de GitHub o LinkedIn con target="_blank".

NIVEL: INTERMEDIO

Reto 2: Formulario de Registro con Validaciones

Objetivo: Crear un formulario de registro completo con:

  • Campo para Nombre completo (texto requerido).
  • Campo para Correo electrónico (tipo email requerido).
  • Campo para Contraseña (tipo password con mínimo 8 caracteres).
  • Menú desplegable <select> para elegir país (México, España, Colombia, Argentina, etc.).
  • Casilla de verificación checkbox para "Acepto los términos y condiciones" (requerido).
  • Botón de tipo submit.
💡 Ver Pistas / Solución Sugerida 
<form action="#" method="POST">
  <div>
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" required placeholder="Ej. Juan Pérez">
  </div>
  <div>
    <label for="email">Correo:</label>
    <input type="email" id="email" name="email" required>
  </div>
  <div>
    <label for="pass">Contraseña:</label>
    <input type="password" id="pass" name="pass" minlength="8" required>
  </div>
  <div>
    <label for="pais">País:</label>
    <select id="pais" name="pais" required>
      <option value="">Selecciona un país...</option>
      <option value="ES">España</option>
      <option value="MX">México</option>
      <option value="CO">Colombia</option>
    </select>
  </div>
  <div>
    <label>
      <input type="checkbox" name="terminos" required> Acepto los términos
    </label>
  </div>
  <button type="submit">Registrarse</button>
</form>
NIVEL: DESAFÍO REAL

Reto 3: Estructura Semántica de un Blog Completo

Objetivo: Maquetar una página de artículo de blog usando exclusivamente etiquetas semánticas:

  • <header> con el logotipo y barra <nav>.
  • <main> conteniendo el <article> principal del blog.
  • El artículo debe tener <h1>, fecha en <time>, párrafos, citas <blockquote> y una imagen dentro de <figure> con <figcaption>.
  • Una barra lateral <aside> con "Artículos relacionados".
  • Un <footer> con derechos de autor y enlaces de privacidad.
