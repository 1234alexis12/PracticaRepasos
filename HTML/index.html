🚀 Fundamentos de HTML5: Lo Esencial y Más Usado

Una guía diseñada paso a paso para dominar la estructura de la web y sentar bases sólidas para continuar con CSS.

🗺️ Ruta de Aprendizaje (Lecciones Prácticas)

Haz clic en cada lección en orden para estudiarla a tu propio ritmo:

  1. Lección 01: Estructura Básica de un Documento HTML
    Doctype, html, head, meta viewport, title, body y anatomía de etiquetas.

  2. Lección 02: Textos, Títulos y Formato
    Jerarquía de encabezados (h1 a h6), párrafos (p), saltos (br, hr) y formato (strong, em, mark, code).

  3. Lección 03: Enlaces e Imágenes
    Hipervínculos (a) absolutos/relativos, target="_blank", imágenes (img), alt para SEO y anclas internas.

  4. Lección 04: Contenedores, Clases e Identificadores (Puente a CSS)
    Bloque vs Línea (div vs span), atributos class e id, reutilización y preparación para dar estilos.

  5. Lección 05: Listas y Tablas de Datos
    Listas ordenadas (ol), desordenadas (ul, base de menús de navegación), y tablas (table, thead, tbody, tr, th, td).

  6. Lección 06: Formularios y Controles de Usuario
    form, label con for, tipos de input (text, email, password, number, date), radio, checkbox, select y botones.

  7. Lección 07: HTML Semántico Moderno
    Maquetación real con header, nav, main, section, article, aside y footer. Crucial para SEO y accesibilidad.

  8. 🛠️ Lección 08: Taller de Retos y Proyectos Prácticos (¡A Programar!)
    3 proyectos reales con retos incrementales: Ficha de Perfil, Formulario con Validaciones y Blog Semántico.

💡 ¿Cómo estudiar este material?

  • No intentes memorizar todo de memoria: La programación web se aprende practicando. Lo importante es que sepas qué existe y para qué sirve.
  • Experimenta: Modifica los textos, añade nuevos párrafos, borra cosas y recarga la página en tu navegador para ver qué cambia.
  • Inspecciona con F12: Pulsa la tecla F12 en tu teclado en cualquier página web para ver su código HTML en tiempo real.

🎯 ¿Qué sigue después de terminar estas 7 lecciones?

Una vez que domines estos archivos, estarás 100% preparado/a para dar el salto a CSS (Cascading Style Sheets), donde aprenderás:

  • Colores, tipografías y sombras.
  • El modelo de cajas (Margin, Border, Padding, Width, Height).
  • Sistemas de maquetación modernos (Flexbox y CSS Grid).
  • Diseño adaptable a teléfonos celulares (Responsive Web Design / Media Queries).

¡Mucho éxito en tu aprendizaje! Tómate tu tiempo y disfruta el proceso.
