## 🧠 El Método Pedagógico: Cómo Aprender a Programar

Para no caer en el temido **"Tutorial Hell"** *(la trampa de consumir cursos sin ser capaz de crear nada por tu cuenta)*, aplica siempre este ciclo de 4 fases en cada módulo:

```
[1. COMPRENDER EL CONCEPTO] ➡️ [2. EXPERIMENTAR Y ROMPER] ➡️ [3. CONSTRUIR EN HOJA EN BLANCO] ➡️ [4. EXPLICAR (TÉCNICA FEYNMAN)]
```

1. **Fase 1: Leer el código comentado (10% de tu tiempo):** Abre el archivo y lee los comentarios explicativos para entender la sintaxis y el porqué.
2. **Fase 2: Modificar y experimentar (20% de tu tiempo):** Cambia valores, altera condiciones, elimina líneas a propósito para ver cómo reacciona el motor al fallar.
3. **Fase 3: El Reto en Hoja en Blanco (50% de tu tiempo — ¡Aquí ocurre el 90% del aprendizaje!):** Cierra el ejemplo, abre un archivo nuevo vacío e intenta resolver el reto sin copiar ni pegar.
4. **Fase 4: La Técnica Feynman (20% de tu tiempo):** Explícate en voz alta cómo funciona tu código como si se lo estuvieras enseñando a alguien que recién empieza.

## 🛠️ ¿Cómo utilizar este repositorio en tu computadora?

### 1. Clonar el repositorio
```bash
git clone https://github.com/1234alexis12/PracticaRepasos.git
cd PracticaRepasos
```

### 2. Ejecutar las lecciones interactivas de Frontend (HTML, CSS, JS)
- Simplemente haz doble clic en cualquier archivo `.html` o abre la carpeta con **Visual Studio Code** y utiliza la extensión **Live Server**.
- Cada una de las 3 carpetas frontend incluye un `index.html` central que sirve de panel interactivo.

### 3. Ejecutar las lecciones de Python
Abre tu terminal en la carpeta `PYTHON/` y corre:
```powershell
cd PYTHON
python 01_primeros_pasos_y_variables.py
```

### 4. Ejecutar las lecciones de SQL en MySQL
Abre tu cliente de base de datos preferido (**MySQL Workbench** o **DBeaver**) y ejecuta los scripts `.sql` ordenadamente del `00` al `09`.

## 👨‍🏫 Consejos de Oro de tu Profesor

1. **La consistencia vence al talento:** Practicar 30 minutos todos los días es 10 veces más efectivo que estudiar 8 horas seguidas solo los domingos.
2. **Los errores y excepciones son tus mejores maestros:** No te asustes cuando la consola se ponga roja; lee el mensaje de error con calma. El 99% de las veces te dice exactamente el archivo y la línea donde ocurrió el problema.
3. **Domina las bases antes de los frameworks:** Si entiendes a fondo JavaScript puro, aprender React, Vue o Node.js te tomará semanas en lugar de meses.
